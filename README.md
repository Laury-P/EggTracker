# EggTracker 🥚

Application Android pour suivre la ponte des volailles.

## 🎯 Objectif
Permettre un suivi quotidien et générer des statistiques simples.
Projet personnel en cours de développement.

## 🏗️ Stack technique
- Kotlin
- Jetpack Compose
- MVVM
- Room
- Retrofit
- Hilt
- DataStore

## 📊 Fonctionnalités MVP
- 3 groupes maximum
- Saisie quotidienne
- Moyenne glissante 7 jours
- Graphique journalier

Phase 3 – Premium
